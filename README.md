## Archive this site on the Wayback Machine

You can ask the [Internet Archive Wayback Machine](https://web.archive.org/) to **crawl and save** Universal Editor so snapshots stay available over time.

### Quick save (recommended)

1. Open the **Save Page Now** tool:  
   **[https://web.archive.org/save](https://web.archive.org/save)**
2. Paste a page URL, for example:
   - `https://universal-editor-203.github.io/`
   - `https://universal-editor-203.github.io/editor.html`
   - `https://universal-editor-203.github.io/changelog.html`
3. Click **Save Page** (or press Enter).
4. Wait until the archive finishes. You will get a permanent snapshot link like:  
   `https://web.archive.org/web/YYYYMMDDhhmmss/https://universal-editor-203.github.io/`

### Save every main page

Run **Save Page Now** once for each important URL:

```text
https://universal-editor-203.github.io/
https://universal-editor-203.github.io/index.html
https://universal-editor-203.github.io/editor.html
https://universal-editor-203.github.io/editor.html#video
https://universal-editor-203.github.io/editor.html#rom
https://universal-editor-203.github.io/editor.html#file
https://universal-editor-203.github.io/editor.html#music
https://universal-editor-203.github.io/editor.html#rust
https://universal-editor-203.github.io/changelog.html
https://universal-editor-203.github.io/styles.css
https://universal-editor-203.github.io/favicon.svg
https://universal-editor-203.github.io/robots.txt

```

### How this repo helps crawlers

| File | Role |
|------|------|
| [`robots.txt`](https://universal-editor-203.github.io/robots.txt) | Allows all bots, including `archive.org_bot` / `ia_archiver` |
| [`sitemap.xml`](https://universal-editor-203.github.io/sitemap.xml) | Lists all public pages for discovery |

Wayback Machine does **not** guarantee automatic crawls of every small site. Using **Save Page Now** is the reliable way to force a snapshot.
