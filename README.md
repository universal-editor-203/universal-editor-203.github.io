## Features

| Module | Description |
|--------|-------------|
| 🎬 **Video** | Filmora-style timeline · media bin · preview · properties · FFmpeg.wasm |
| 🎮 **ROM** | Organize & inspect game ROMs in-browser |
| 📄 **File** | Text / code edit + download |
| 🎵 **Music** | Load & preview audio |
| 🦀 **Rust** | Write, template, download `.rs` |

Also includes:

- Shared `styles.css` design system
- New **favicon.svg** (black & orange mark)
- **Astro** starter structure under `/astro`
- Companion **Next.js** repo: [universal-editor-next](https://github.com/universal-editor-203/universal-editor-next)
